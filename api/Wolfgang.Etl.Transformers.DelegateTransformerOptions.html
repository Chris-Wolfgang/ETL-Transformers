Remarks

Per ADR-0009, stage configuration is supplied as a record passed to the constructor rather than set through mutable properties, so a transformer is configured once and not reconfigured during a run. This record is shared by the transformers that accept it, because the one setting they need is the same; SelectTransformer<TSource, TDestination> and SelectManyTransformer<TSource, TDestination> accept it today. It is left unsealed so a transformer that later grows its own settings can derive from it.

It deliberately does not derive from Wolfgang.Etl.Abstractions.TransformerOptions. That record also carries SkipItemCount, MaximumItemCount and ReportingInterval, which the transformers in this library do not implement - they carry no counters by design - and which are already expressed here by the dedicated SkipTransformer<T> and TakeTransformer<T> stages. Inheriting them would advertise settings that are silently ignored and give the same concept two spellings.

The pass-through and windowing transformers (PassThroughTransformer<T>, TakeTransformer<T>, SkipTransformer<T>, ChunkTransformer<T>, BufferedTransformer<T> and ProgressReportingTransformer<T>) invoke no caller delegate, so they have nothing to apply a policy to and do not accept this record.

Properties

ErrorPolicy

The policy applied when the caller-supplied delegate throws while handling one item.

public Func<ItemErrorContext, ItemErrorAction> ErrorPolicy { get; init; }

Property Value

Func<ItemErrorContext, ItemErrorAction>

A function receiving an Wolfgang.Etl.Abstractions.ItemErrorContext describing the failure and returning Wolfgang.Etl.Abstractions.ItemErrorAction.Skip to drop the item and continue, or Wolfgang.Etl.Abstractions.ItemErrorAction.Abort to re-throw. Defaults to a policy that always returns Wolfgang.Etl.Abstractions.ItemErrorAction.Abort, which is the behaviour of a transformer constructed without this record: the exception propagates to the caller unchanged.

Remarks

Ready-made policies - including skip-and-log and skip-to-dead-letter forms - are available from ItemErrorPolicy in the Wolfgang.Etl.ErrorPolicies package. This library does not reference that package; the policy is just a delegate.
