Examples

// narrow a heterogeneous object stream to strings, asserting that every item is one
var strings = new CastTransformer<object, string>();

// downcast every Animal to Dog (assumes the upstream guarantees this)
var dogs = new CastTransformer<Animal, Dog>();

Remarks

CastTransformer<TSource, TDestination> is the transformer equivalent of LINQ's Cast<TResult>(IEnumerable): it casts every input item to TDestination and throws InvalidCastException if any item does not have a runtime conversion to that type.

There are three ways to handle an item that does not convert, and they differ in what you learn about it:

  • This type with no options - the default - throws InvalidCastException and ends the run at the first mismatch.
  • OfTypeTransformer<TSource, TDestination> filters mismatches out silently: no exception, no count, no record of what was dropped. Reach for it when a mixed sequence is expected and the mismatches are of no interest.
  • This type with a DelegateTransformerOptions whose ErrorPolicy returns Wolfgang.Etl.Abstractions.ItemErrorAction.Skip also drops mismatches, but accounts for them: each one is counted in CurrentErrorItemCount and passed to the policy, which can log it or route it to a dead-letter collection. Reach for it when mismatches are unexpected and you need to know which ones occurred.

Implements only Wolfgang.Etl.Abstractions.ITransformAsync<TSource, TDestination> - no progress, no cancellation, no Skip/Max - to keep the hot loop minimal. The one counter is the opt-in CurrentErrorItemCount, which stays at zero on the default path.
